# Revisar una especificación

1. ¿Está claro qué se quiere y para quién? Si hay dos lecturas, pregunta.
2. ¿Hay criterios de aceptación comprobables (positivo, negativo, límite)?
3. ¿Falta decidir datos, migraciones, compatibilidad, permisos o UI?
4. ¿Se pide tocar rutas protegidas, CI o algo destructivo? Márcalo.
5. Escribe preguntas concretas, en orden: primero lo que bloquea empezar. Si no
   falta nada, responde `Sin preguntas: la spec está lista.`
