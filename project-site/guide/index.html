Esencial

Una app personal de comidas + entrenamiento desplegada como un solo Worker de Cloudflare: API Hono bajo /api/*, SPA React servida como assets estáticos, y SQLite (D1) como única base de datos. Esta guía la explica página a página, con el código real del repo.

El proyecto en una frase

Cada día abres la app y ves tu día: qué cocinar (desayuno/almuerzo/cena del plan semanal), qué entrenar (la plantilla de fuerza programada) y tus notas. Todo lo demás —recetario, catálogo de ejercicios, lista de la compra— existe para alimentar esa pantalla.

Lo que hace la app (dominio)

🍎 Recetario

Recetas con ingredientes por ración, pasos, materiales, foto y tags.

📅 Plan semanal

Rejilla 7 días × 3 comidas. Asignas recetas a huecos por semana ISO.

🛒 Lista de compra

Se agrega al vuelo desde el plan: nunca se guarda; mezcla items manuales.

💪 Plan de fuerza

Plantillas A/B/C con ejercicios, series y rangos de reps. Se programan por fecha.

📝 Registro de sesión

Kg × reps por serie, esfuerzo 1–5. Al cerrar, el día queda solo lectura.

📓 Día

Pantalla índice: un solo GET que junta comidas + sesión + nota del día.

Cómo se construyó (y por qué te suena)

El repo usa OpenSpec: cada épica (E0–E7) vive en openspec/changes/archive/ con proposal.md → design.md → tasks.md → specs/. Los specs tienen traducción legible en español (spec-lectura-es.md) — esta guía es su complemento visual.

Para leer en orden: Arquitectura → Datos → API → Frontend. Cada página es autónoma y enlaza el archivo real del repo.
